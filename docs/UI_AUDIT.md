# OpenTV-Remote 0.8.2: visible presets and independent appearance

Preset selection is now a full-screen gallery with drawings generated from the same candidate canvas that is applied. Browsing previews has no ViewModel transport/command handlers. Eight use cases are distinct: Classic, Live TV, Streaming, Touchpad, Minimal, Big buttons, Full remote and Numbers & touch. Minimal contains only daily navigation/volume/Back/Home; Streaming excludes channel controls and emphasizes apps/playback. Full remote adapts the approved All controls grouping into an editable main remote. Capability filtering and bounded placement remain enforced.

Left/Right hand is a separate persisted choice above the gallery. It swaps side rockers in built-in previews/applied templates and All controls. Numeric order, arrow directions, Back/Home order and previously saved custom geometry do not reverse. The gallery explains the scope. Named presets retain geometry and referenced app targets, including their hand arrangement; unsupported controls are explained before applying. Save current, delete confirmation, Undo and Done/Cancel remain available. Large text uses one preview column and a compact accessible Save action.

Appearance is a separate menu/header entry. Six color choices and a custom visual color picker (saturation/brightness field, rainbow hue slider, optional fine controls and RGB hex) preview coordinated dark backgrounds, raised surfaces, accent, outlines and the in-app logo. Theme colors use Compose MaterialTheme instead of global hard-coded green constants. Custom seeds are lightened when needed for text/control contrast; brand marks and error semantics retain their colors. Cancel does not write preferences. The chosen color is independent of layouts, named presets and hand preference. Large-text color options use two columns.

Join has moved from Presets to the selected-item editor bar. It appears only when touching matching keys form a supported group and affects only the selected group. Split replaces it for a joined item. Deleting an item removes wholly empty rows with Undo. A contextual Remove empty rows action clears remaining gaps when requested; movement does not unexpectedly shift the highlighted destination. Loading existing layouts still preserves internal spacing.

Volume/channel rails now differ by icon shape as well as labels: speaker icons with the selected accent for volume, neutral +/− for channels. Targets, positions and hold behavior are retained. The live renderer, All controls, picker and miniature preset drawings share that distinction.

Resize now uses a bounded downward cascade: colliding lower controls move together, groups retain dimensions, and independent columns remain fixed. Drawing uses the same candidate model as release; shifted neighbors are visible with accent outlines while dragging. The board grows to include the proposed cascade. Exact-size controls share the operation. A rejected boundary/above-control collision leaves the original canvas untouched, and Undo restores the whole pre-resize layout. Normal dragging still preserves its prior placement/swap behavior.

The editor retains automatic trailing height, drag resize, invalid/allowed drop highlights, inactive previews, 48dp targets and native accessibility names. Existing TV mappings, saved apps, pairing and manual widgets are preserved. Executed checks and hardware limits are in TESTING.md. Current screenshots are in screenshots/current.
