# Bundled shortcut icons

YouTube and Netflix vector paths were retrieved from [Simple Icons](https://github.com/simple-icons/simple-icons) on 25 October 2026, under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Sources: [YouTube SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/youtube.svg), [Netflix SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/netflix.svg). YouTube uses its red/white mark; Netflix uses its red N. They identify user shortcuts and do not imply affiliation. Trademark rights remain with their owners.

Android shortcut symbols use Material Icons. iOS uses system SF Symbols and the same credited YouTube/Netflix paths as vector image sets in `ios/OpenTVRemote/Assets.xcassets`. The OpenTV-Remote mark is original vector artwork; its iPhone launcher PNG is generated from `ios/scripts/GenerateIcon.swift`. No remote icon service or arbitrary image URL is contacted by the app.
